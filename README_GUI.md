# 天气服务 GUI 界面

这是基于Gradio的天气服务图形用户界面，为天气服务MCP服务器提供了直观的可视化操作方式。
主程序：weather_gui.py

## 功能特性

- 基于地区名称快速查询天气信息
- 支持获取实时天气数据
- 可选择不同天数的天气预报（3天、7天、10天、15天、30天）
- 友好的界面设计，显示温度、湿度、风向等关键天气指标
- 支持天气状态图标显示
- 提供API密钥设置检查功能

## 安装指南

### 1. 确保已安装Python

请确保您的系统已安装Python 3.7或更高版本。

### 2. 安装项目依赖

```bash
pip install -r requirements.txt
```

这将安装以下主要依赖：
- mcp>=1.14.1
- fastmcp>=2.12.3
- gradio>=3.35.0

### 3. 设置API密钥

天气服务需要有效的API密钥才能正常工作。请按照以下步骤设置环境变量：

#### Windows系统

**临时设置（仅当前会话有效）**：

```cmd
set WEATHER_API_KEY=your_api_key_here
```

**永久设置**：

1. 右键点击"此电脑"或"计算机"，选择"属性"
2. 点击"高级系统设置"
3. 点击"环境变量"
4. 在"系统变量"区域，点击"新建"
5. 变量名输入 `WEATHER_API_KEY`，变量值输入您的实际API密钥
6. 点击"确定"保存

#### Linux/macOS系统

**临时设置（仅当前会话有效）**：

```bash
export WEATHER_API_KEY=your_api_key_here
```

**永久设置**：

编辑您的shell配置文件（如`~/.bashrc`、`~/.zshrc`等），添加以下行：

```bash
export WEATHER_API_KEY=your_api_key_here
```

保存后，运行以下命令使其生效：

```bash
source ~/.bashrc  # 或对应您的shell配置文件
```

## 运行GUI应用

安装完成并设置好API密钥后，可以通过以下命令启动GUI应用：

```bash
python weather_gui.py
```

应用启动后，将会自动在默认浏览器中打开GUI界面，地址为：http://127.0.0.1:7860

## 使用说明

### 查询天气

1. 在"请输入地区名称"输入框中输入您想查询的地区名称（例如：北京、上海、福州）
2. 在"选择预报天数"选项中选择您需要获取的天气预报天数（3天、7天、10天、15天、30天）
3. 点击"查询天气"按钮
4. 查询结果将显示在下方的文本框中，包括：
   - 地区名称
   - 实时天气状态
   - 实时温度
   - 体感温度
   - 风向和风力
   - 湿度
   - 未来几天的天气预报（包含日期、白天/夜晚天气、温度范围）

### 检查API密钥设置

点击"检查API密钥设置"按钮可以验证您的API密钥是否已正确设置。

## 常见问题

### API密钥错误

如果出现"API密钥未设置"或类似错误，请检查您的环境变量是否正确设置了`WEATHER_API_KEY`。

### 地区未找到

如果查询结果显示"未找到该地区"，请尝试使用更精确的地区名称，例如使用"北京市"代替"北京"。

### 端口占用

如果启动时出现端口8000或7860已被占用的错误，请尝试关闭占用该端口的程序，或修改代码中的端口设置。

### 天气数据获取失败

如果出现"获取天气数据失败"的错误，可能是由于网络问题或API服务暂时不可用，请稍后重试。

## 注意事项

- GUI应用需要依赖原有的weather_mcp_server.py文件中的函数，请勿删除或移动该文件
- 确保您的API密钥有效且有足够的调用配额
- 在生产环境中，请确保API密钥的安全，避免泄露
- GUI应用默认仅在本地可访问，如果需要远程访问，请修改`share=True`参数
